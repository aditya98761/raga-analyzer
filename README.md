# Hindustani Raga Practice Analyzer

> Real-time feedback system for Hindustani Classical Music practice — trained on the Saraga Hindustani dataset.

## System Architecture

```
Browser (AudioWorklet) ──── WebSocket ──── FastAPI Backend
        │                                        │
        │                               ┌────────┴────────┐
        │                          FAST LOOP         SLOW LOOP
        │                        PitchEngine         RagaScorer
        │                        torchcrepe-tiny     DTW matching
        │                        ~50ms               ~1.5s
        │                               │
        ▼                               ▼
   Live Pitch Contour          Raga Match % + Stability
   Swar Overlay                Breakdown scores
```

## Quick Start

### 1. Install Dependencies

```bash
pip install -r backend/requirements.txt
```

> **GPU Note**: Install `onnxruntime-gpu` for CUDA inference.
> If you don't have a CUDA-capable GPU, replace with `onnxruntime`.

### 2. Download the Dataset

```bash
python data_pipeline.py --download
```

This downloads ~8 GB from Zenodo (saraga1.5_hindustani.zip) via mirdata.

### 3. Run the Data Pipeline

```bash
# Full run (all tracks, with augmentation)
python data_pipeline.py

# Quick test (first 5 tracks)
python data_pipeline.py --dry-run
```

Outputs to `features/`:
- `train.npz`, `val.npz`, `test.npz` — pitch histograms + mel spectrograms + labels
- `class_weights.npy` — for balanced training
- `label_encoder.pkl` — raga name ↔ integer mapping
- `metadata.json` — raga list and feature dimensions

### 4. Train the Raga Classifier

**Option A — Local (RTX 3050, ~30 min)**:
Open `train_raga_classifier.ipynb` locally and run all cells.
Uses Architecture B (pitch histograms) for fast local training.

**Option B — Google Colab (recommended for CNN on mel specs)**:
1. Upload `features/` to Google Drive
2. Open `train_raga_classifier.ipynb` in Colab
3. Select Runtime → GPU (T4)
4. Run all cells — exports `raga_classifier.onnx` at the end
5. Download and place in `backend/models/raga_classifier.onnx`

### 5. Test Pitch Engine (standalone)

```bash
# Calibrate tonic (sing Sa for 3 seconds)
python pitch_engine.py --calibrate

# Live mic test
python pitch_engine.py --test-mic --tonic 220

# Auto-calibrate then test
python pitch_engine.py --test-mic
```

### 6. Test Raga Scorer (standalone)

```bash
python raga_scorer.py --test-raga Yamangit init
python raga_scorer.py --test-raga Bhairav
```

### 7. Start the Server

```bash
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

Open `http://localhost:8000` in Chrome or Edge.

## Usage Guide

1. **Select a Raga** from the dropdown (populated from `raga_grammar.json`)
2. **Click "Calibrate Sa"** — sing or play your Sa (tonic) for 3 seconds
3. **Click "Start Practice"** — grants microphone access and starts streaming
4. **Sing** — watch the pitch contour, raga graph, and scores update in real-time

### Reading the UI

| Panel | What it shows |
|---|---|
| **Pitch Contour** | Your sung pitch (Sa-relative) scrolling left. Gold trace = voiced. Swar lanes coloured by type (shuddha/komal/tivra). |
| **Raga Structure** | Aroha/avaroha nodes. Green = note you just sang correctly. Red = note outside raga scale. Gold = Vadi, pale gold = Samvadi. |
| **Raga Match %** | Composite score: swar conformance (35%) + transitions (25%) + pakad DTW (25%) + vadi emphasis (15%) |
| **Pitch Stability** | How steady your sustained notes are. High = clean sustain. Low = wavering/vibrato. |

## Known Limitations

- **Small dataset**: Saraga Hindustani has ~165 recordings across ~25 ragas. Rare ragas with ≤3 recordings will have lower classifier accuracy.
- **Raga grammar**: The `raga_grammar.json` uses equal-tempered cents approximations. Microtonal inflections (komal Ga in Darbari's andolan) are simplified to fixed cent values.
- **Latency**: Real-time pitch detection adds ~50-100ms. On slow CPUs, pYIN fallback may add up to 200ms.
- **Browser support**: AudioWorklet requires HTTPS or localhost. Safari partial support.

## Extending the System

### Adding a New Raga
Edit `raga_grammar.json` and add an entry following the existing schema.

### Training Your Own Classifier
The notebook supports both Architecture A (CNN on mel specs) and B (FC on pitch histograms). Swap in your own features by editing the `DataLoader` cells.

### Running on CPU Only
```bash
pip install onnxruntime   # instead of onnxruntime-gpu
```
The pitch engine will automatically use `librosa.pyin` on CPU.
